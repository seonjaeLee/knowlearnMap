# React 작업 트리 (SVN `knowlearnmap/react` 동기)

- **편집·빌드·SVN 업로드 기준**: 이 `react/` 폴더
- **로컬 실행**: 저장소 루트에서 `npm run dev` (또는 `cd react && npm run dev`)
- **문서**: `react/docs/` (UI·스펙·히스토리)
- **루트 `src/`·`docs/`**: 제거됨. 신규 수정은 `react/`만 사용

## SVN 반영

Windows 원격 작업본 경로와 동일하게 `react/src/...` 구조로 commit.
