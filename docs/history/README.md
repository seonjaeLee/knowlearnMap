# UI 작업 이력

## 어떤 파일을 쓸까

| 파일 | 역할 |
|------|------|
| **[ui-history2.md](./ui-history2.md)** | **현행** 작업 기록 (2026-05-16~, 툴바·검색·목록 spec 등) |
| **[ui-history.md](./ui-history.md)** | **아카이브** (분리 이전 누적분) |

`ui-history.md`가 길어져 **ui-history2**로 이어서 기록 중입니다.

---

## 갱신 규칙

- **에이전트는 사용자가 명시적으로 요청할 때만** 항목을 추가합니다.  
  (예: 「히스토리에 적어줘」, 「ui-history2에 남겨줘」)
- 자동으로 UI 작업마다 기록하지 **않습니다**.
- Cursor 규칙: `.cursor/rules/ui-history-on-request.mdc`

---

## 작성 형식

- 파일 상단의 번호·날짜·섹션 관례를 따릅니다.
- 새 항목은 보통 **ui-history2.md**에 추가합니다.
